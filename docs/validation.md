# 검증 범위

2026-10-29 추가: WXS CLI 0.4.0의 표 포함 본문 삽입, 실제 서버 임시저장 성공 메시지와 저장 후 본문 페이지 PNG를 확인했다. 상세한 실기·모의 시험 구분은 [WXS 기술 설명](../skills/wxs-cli/references/architecture.md)의 0.4.0 항목을 따른다. Python 49개 시험과 JavaScript 고정 액션 시험을 실행한다. 상신은 수행하지 않았다.

기준일: 2026-10-15. 이번 팩 통합 과정에서는 실제 업무 문서를 변경하거나 상신하지 않았다. 기존 실기 확인과 새 배포본의 로컬 검증을 구분한다.

| 대상 | 기존 확인 | 남은 확인 |
| --- | --- | --- |
| 충북 업무포털 | 공개 로그인 화면, 사용자가 로그인한 Chrome 세션의 나이스/에듀파인 SSO 진입 | 실제 인증서 선택·암호 자동 입력 |
| 인증서 도우미 | 가짜 정보로 Windows PowerShell 5.1/7 DPAPI 저장·복호화, 한글, ACL, 덮어쓰기 방지, 비밀값 없는 Status | 각 사용자 실제 인증서 등록·로그인 |
| 나이스 | 사용자 허가의 더미 연가/조퇴 1시간 입력, 승인요청으로 준비창 열기, 기존 개인결재선 지정, 최종 미상신 | 직접 결재자 구성, 다른 복무 유형·기관, 실제 신청·상신·상태 조회 |
| 에듀파인 | 기간·제목·기안자 검색, 전체 1페이지와 개별 문서정보 대조 | 다수 페이지 이동, 다른 기관·기간, 진행 문서 등 다른 메뉴 |
| WXS 조회 | 배포 CLI의 inspect/text/attachments/draft-status, 대표 공문 724자 추출, 편집 상태 동일, 프레임 오류 없음 | 첨부 파일 내용·그림·관인·문서 배치 |
| WXS 쓰기 | 제공된 원본 팩의 설정·고정 액션·실행 절차 오프라인 시험. 이전 연구 스크립트의 실제 임시저장 기록 | 범용 배포본 전체 흐름의 실제 서버 임시저장 재검증, 다른 지역·기관·버전 |

실제 문서 목록·원문·스크린샷·개인 결재자·인증서·세션 값은 이 공개 배포본에서 제외했다. 기존 조퇴 시험의 저장된 경로에는 현재 소속과의 불일치가 있어 실제 신청 전에 다시 확인해야 했다. 이런 경로를 설치 기본값으로 넣지 않는다.

새 배포본에서 재현할 로컬 점검:

통합 배포본 로컬 검증 결과: **Python 27개 + JavaScript 11개, 총 38개 통과**. 원본 WXS 30개 시험에 설치·갱신·구 이름 호환 4개와 링크·구문·배포 설정 4개를 더했다. 신규 설치, 동일 내용 재설치, 충돌 시 전체 사전 중단, 갱신 전 백업, 기존 추가 파일 보존, 구 이름의 호환 전환을 격리된 임시 폴더에서 확인했다. 스킬 5개(실행 스킬 4개 + 구 이름 호환 1개)의 형식 검사도 통과했다. WXS 실행 소스는 원본과 바이트 단위로 동일하다.

```powershell
python -X utf8 -m unittest discover -s tests -p 'test_*.py' -v
node tests/test_actions.cjs
.\validate.ps1
```
