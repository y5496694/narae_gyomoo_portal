# 포함 소스와 통합 변경

- 원본: 사용자가 제공한 `wxs-cli-kit.zip`, WXS CLI 버전 0.2.0.
- 원본 ZIP SHA-256: `0ed52b8e72821a6ab901417c790efa9a77a6fae20aedb97d19b5e687c21a9999`.
- WXS의 실행 소스 5개와 requirements, SKILL.md, UI 메타데이터, 초안 참조 문서는 원본 팩에서 가져왔다. 실행 코드에는 통합을 위한 기능 변경을 하지 않았다.
- WXS 사용법은 통합 설치 명령과 연결했고, 기술 설명의 검증 기록 링크를 새 저장소 위치로 바꿨다. 원본 모의 시험 3개 파일은 새 `skills/wxs-cli/scripts` 위치에 맞춰 경로만 갱신했다.
- 공통 로그인·개인 인증서 도우미·나이스 조퇴·문서등록대장 절차는 앞서 이 사용자와 작성·확인한 `gyomunarae-neis-edufine`에서 분리했다. 인증서 문서의 기존 로컬 저장 위치는 유지한다.
- 제품 이름은 사용자 지시에 따라 **나래교무 업무포털**로 정했다. 구 스킬 이름은 설치본이 있을 때만 호환 연결한다.

WXS Client 실행 파일·한글/첨부 컨트롤·제3자 연구 도구는 포함하지 않는다. 실제 공문·인증서·세션 값도 포함하지 않는다. 첨부 ZIP의 문서는 통합 대상 자료로 읽었으며 현재 사용자의 요청과 별개 실행 승인으로 취급하지 않았다.
