WXS (공문서 에디터) CLI 0.2.0 검증 기록 — 2026-10-15

환경: Windows, Python 3.13.5 64비트, pywin32 사용 가능, Node.js 24.16.0(모의 시험용).
일반 실행에 Node.js 또는 REA는 필요하지 않습니다.

배포본 실제 조회
- windows, inspect, text, attachments, draft-status 성공.
- 실제 공문 본문 724자 추출, 추출 전후 editor 상태 동일.
- 프레임 접근 오류 0, HwpCtrl 2개 식별.
- draft-status에서 읽기 전용 EditMode=0 확인.
- 실제 공문 본문·제목·파일 목록·세션 값은 이 기록에 포함하지 않았습니다.

오프라인 모의 시험: 총 30개 통과
- Python 설정/CLI 시험 13개: 필수값, 알 수 없는 키/상신 키 거부, JSON 중복 키,
  줄바꿈/UTF-8 BOM, 상대 경로, 실제 파일 크기, 누락/빈/중복 첨부,
  비공개 사유 타입/범위, 후보 설정, 명시 hwnd 및 기존 출력 파일 보호.
- Python 실행 절차 시험 6개: 저장 성공 메시지 확인, 동일 이름 기본 취소,
  정확한 이름의 명시적 교체, 다른 이름/상신 메시지 미확인,
  잘못된 대상/기존 결재경로에서 변경 전 중단.
- JavaScript 고정 액션 시험 11개: 상신/임의 코드 명령 거부, 읽기 전용 문서 보호,
  과제카드 정확 일치·중복, 결재자 동명이인·ID, 기관 전체 명칭,
  비공개 사유 동기화, 자동발송 설정만 수행, 다중 관인 중단,
  첨부 컨트롤 거부 처리, Prototype.js 배열 직렬화, 임시저장 전용 함수.
- 설치 도우미 신규 설치·업데이트 및 skills 폴더 밖 백업 동작 확인.
- Python 소스 구문 검사 및 SKILL.md 검사 통과.

패키지 폴더에서 재현:
  python -X utf8 -m unittest discover -s .\tests -p 'test_*.py' -v
  node .\tests\test_actions.cjs

Python 실행 절차 시험은 Windows/pywin32가 필요합니다.
모의 시험은 실제 앱·서버·인증서·네트워크를 사용하지 않습니다.
