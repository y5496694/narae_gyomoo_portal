# 나래교무 업무포털 — 에듀파인

[업무포털 공통 지침](../narae-gyomu-work-portal/SKILL.md)을 읽고, 로그인/진입이 필요하면 해당 스킬의 공통 로그인 절차로 K-에듀파인에 들어간다. 웹 화면은 브라우저 컨트롤, 열린 공문서 에디터는 WXS CLI가 담당한다.

| 요청 | 절차 |
| --- | --- |
| 문서 검색·기안자별 목록·문서정보 확인 | [문서등록대장](references/document-register.md) |
| 진행 중인 문서·공람대기·공람완료 확인 | [진행 문서와 공람](references/circulation.md) |
| 검색한 공문 열람·열린 표준 양식 작성·임시저장 | [WXS 연결](references/wxs-cli.md) → [WXS 스킬](../wxs-cli/SKILL.md) |

문서등록대장은 **문서관리 → 문서함 → 문서등록대장**이다. 상대 기간을 실제 날짜로 확정하고 등록일자·기안일시를 구분한다. `기안(접수)자` 이름만으로 기안자를 확정하지 말고 기안문서 여부와 문서정보의 기안 처리자를 대조한다. 전체 건수와 확인한 페이지를 보고한다.

공문 내용 확인의 핵심은 **본문을 실제로 읽는 것**이다. 제목·목록·문서정보만으로 내용 확인을 완료하지 않는다. 문서 제목을 눌러 WXS가 열리면 **나래교무 업무포털 팩에 포함된 WXS CLI만** 사용한다. 별도 COM/Win32 스크립트·다른 WXS 도구·GUI 자동화로 우회하지 않는다. CLI 내부에서 지원하는 COM/Win32 처리는 이 제한에 해당하지 않는다.

공람 조회 기본값은 **오늘부터 역산한 최근 한 달**이다. 대기와 완료를 같은 날짜로 조회하고 전체 건수와 모든 페이지를 대조한다. 문서는 **한 건씩 열어 본문과 모든 첨부 내용을 읽고 창을 닫은 뒤 다음 건**을 연다. 백그라운드 옵션을 우선하되 최초 창 활성화까지 방지된다고 보장하지 않는다. 첨부는 [포함된 형식별 읽기 도구](../wxs-cli/references/attachments.md)를 사용하고 HWP/HWPX는 나래 한글 오피스 CLI로만 읽는다. 읽지 못한 본문·첨부는 미확인으로 남긴다.

문서등록대장·문서진행·업무담당확인·공람대기·공람완료의 조회 경로를 확인했다. 조회·초안·임시저장 요청을 실제 상신·결재 허가로 확대하지 않는다. 사용자가 특정 공문의 상신·결재를 명시하면 [상신·결재 절차](../../docs/final-actions.md)와 WXS CLI로 처리한다. 접수·발송·삭제는 이번 지원 범위가 아니다. 실제 공문·개인정보·세션 값을 공개 스킬이나 배포 문서에 저장하지 않는다.
