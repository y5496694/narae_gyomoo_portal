# 나래교무 업무포털 — 에듀파인

[업무포털 공통 지침](../narae-gyomu-work-portal/SKILL.md)을 읽고, 로그인/진입이 필요하면 해당 스킬의 공통 로그인 절차로 K-에듀파인에 들어간다. 웹 화면은 브라우저 컨트롤, 열린 공문서 에디터는 WXS CLI가 담당한다.

| 요청 | 절차 |
| --- | --- |
| 문서 검색·기안자별 목록·문서정보 확인 | [문서등록대장](references/document-register.md) |
| 검색한 공문 열람·열린 표준 양식 작성·임시저장 | [WXS 연결](references/wxs-cli.md) → [WXS 스킬](../wxs-cli/SKILL.md) |

문서등록대장은 **문서관리 → 문서함 → 문서등록대장**이다. 상대 기간을 실제 날짜로 확정하고 등록일자·기안일시를 구분한다. `기안(접수)자` 이름만으로 기안자를 확정하지 말고 기안문서 여부와 문서정보의 기안 처리자를 대조한다. 전체 건수와 확인한 페이지를 보고한다.

문서 제목을 눌러 WXS가 열리면 문서 제목·번호와 실제 창을 대조한 뒤 WXS 스킬로 이어간다. **컴퓨터 유즈는 사용하지 않는다.** 첨부 목록 조회와 파일 내용 열람을 구분한다. 본문을 읽지 않았으면 제목만으로 내용을 요약하지 않는다.

현재 웹 구현은 문서등록대장 검색과 문서정보 조회다. 기안 양식을 여는 다른 웹 메뉴, 진행 문서·결재 상태·접수 처리 등은 추가 구현·검증 대상이다. 요청한 조회·초안·임시저장 범위를 지키고 상신·승인·실제 발송은 수행하지 않는다. 실제 공문·개인정보·세션 값을 공개 스킬이나 배포 문서에 저장하지 않는다.
