# 나이스 조퇴 초안과 결재경로 지정

## 범위와 검증 상태

2026-10-15 충북 4세대 나이스에서 확인한 실제 경로는 **기본 메뉴 → 복무 → 개인근무상황관리 → 신청 → 근무상황신청**이다. 신청 화면에서 대분류 **연가**, 소분류 **조퇴**를 선택한다. 사용자의 ‘개인 복무 관리’ 표현은 이 환경의 ‘개인근무상황관리’에 해당한다. 메뉴·권한이 다르면 현재 화면으로 재확인한다.

이번 지원 범위는 조퇴 내용 입력과 결재경로 지정 후 **최종 상신 직전에서 정지**하는 것이다. 이 환경의 **근무상황신청 → 승인요청**은 **기안문서상신** 준비창을 여는 단계이며 최종 상신과 다르다. 결재경로를 지정하기 위해 이 단계까지 이동할 수 있다. **기안문서상신 창의 상신 버튼은 누르지 않는다.** 다른 화면의 비슷한 버튼에 이 동작을 일반화하지 않는다.

## 필수 정보

- 신청 날짜, 시작·종료 시각, 사유. 사용자 또는 개인 설정에서 확인한다.
- 실제 복무 종류와 화면의 연가·조퇴 구분. 사용자가 말한 유형과 현재 표시가 일치하는지 확인한다.
- 결재경로: 사용자 지정 또는 사용자가 사용을 허용한 저장된 경로. 결재자·순서·역할을 확인한다.

실제 신청은 사용자가 제공한 값을 사용한다. 사용자가 **더미데이터로 상신 전 테스트를 하도록 명시적으로 허용한 경우**에는 테스트임을 분명히 표시한 사유와 확인 가능한 근무일·시간을 정해 입력할 수 있다. 이 경우 날짜·시간·사유를 다시 묻지 않는다. 결재자는 가상 인물로 만들지 않고 화면에서 확인한 기존 개인 결재경로를 미리보기로 우선 사용한다. 후보 경로가 여러 개이고 기본 경로도 없으면 경로 구조를 확인한 지점까지 보고한다. 더미 입력은 상신하지 않으며 불필요한 서버 저장을 피한다.

더미 테스트 허가도 없고 실제 값도 없으면 입력 화면과 저장된 결재경로의 구조까지 확인하고 실제 초안을 채우는 단계에 필요한 정보를 요청한다. 같은 정보가 이미 제공됐다면 다시 묻지 않는다.

## 브라우저 절차

1. 업무포털의 나이스 링크로 실제 나이스 탭에 들어가 로그인된 사용자와 화면을 확인한다. Chrome의 제어 탭 목록이 비어 있으면 `browser.user.openTabs()`로 기존 사용자 탭을 조회하고 해당 업무 탭을 선택한다. 제어 탭이 없다는 이유만으로 로그인 세션이 없다고 단정하지 않는다.
2. **복무 → 개인근무상황관리 → 신청(새 창 열림)**을 연다. 실제로는 같은 브라우저 탭 안의 **근무상황신청** 대화상자로 열렸다. 새 탭이 없다고 실패로 판단하거나 신청 버튼을 반복해서 누르지 않는다. 대화상자가 로딩된 뒤 현재 DOM을 다시 확인한다.
3. **근무상황대분류=연가, 근무상황소분류=조퇴**로 선택한다. 대분류 기본값이 연가여도 확인한다. 신청기간 시작/종료일자, 시작 시·분, 종료 시·분, 사유 또는 용무를 입력한다. 시작일을 바꾸면 종료일도 따라 바뀌었으므로 두 값을 다시 대조한다. 화면이 계산한 일·시간·분과 상단 신청목록의 반영값을 확인한다.
4. 콤보상자는 일반 HTML select가 아닌 접근성 **combobox → option** 구조다. 목록을 클릭해 실제 옵션을 선택하거나 방향키로 바꾸고 변경된 표시를 확인한다. 5분 단위 분 선택에서 00이 가상 목록 밖이면 방향키를 사용해 이동할 수 있다. 날짜·사유 입력 뒤 Tab으로 포커스를 이동시켜 화면 데이터에 반영한다. 고정된 방향키 횟수를 다른 초기값에 재사용하지 않는다.
5. **승인요청**으로 **기안문서상신** 대화상자를 연다. 기안내용에 날짜·시간·조퇴·사유가 맞게 들어왔는지 확인한다. **개인결재선 → 개인 결재선 지정**에서 업무에 맞는 기존 경로를 선택하고, 하단 결재선 조회가 완료될 때까지 확인한 뒤 **지정**을 누른다. 직접 구성해야 하면 화면의 **결재자지정**을 사용하되 이 방식은 이번 시험에서 실행하지 않았다.
6. 기안문서상신의 결재선 표에서 기안자, 검토·결재자의 성명·현재 소속·역할·순서를 대조한다. 저장된 개인결재선의 소속이 현재 학교와 다르면 실신청용으로 적합하다고 단정하지 않는다. 이번처럼 사용자가 더미 테스트를 허용한 경우 미상신 미리보기 적용은 가능하나 불일치를 결과에 명시한다. 실제 신청은 올바른 경로를 확인하기 전 진행하지 않는다.
7. **상신을 누르지 않고** 해당 탭과 검증 화면을 유지한다. 이번 화면에는 별도 임시저장 버튼을 사용하지 않았으며, 최종 준비 화면 진입이 서버에서 어떤 임시 기록을 만드는지까지 검증한 것은 아니다. 별도 저장하지 않았다는 사실과 서버에 아무 기록도 없다는 단정을 구분한다.

결과에는 완료한 단계, 입력한 신청 날짜·시간, 결재경로 확인 여부, 임시저장 여부, **미상신** 상태와 남은 작업을 표시한다. 화면 확인 자료를 남길 때 주민번호 등 요청과 무관한 개인정보가 포함되지 않도록 한다.

## 검증 기록

2026-10-15: Chrome에서 업무포털 로그인 후 나이스 진입, 복무 → 개인근무상황관리 → 신청, 연가 → 조퇴, 2026-10-16 15:00~16:00(0일 1시간 0분)과 더미 사유 입력, 승인요청 → 기안문서상신 → 개인결재선 → 기존 조퇴/관내출장 경로 → 지정까지 실기 확인했다. 최종 화면의 기안내용과 기안·검토·결재 행을 대조하고 **상신을 누르지 않은 상태**로 정지했다. 별도 저장/상신은 실행하지 않았다. 기존 경로의 검토·결재자는 현재 학교와 다른 소속으로 표시돼 실제 사용 전 재확인이 필요하다. 이름·ID·상세 HR 정보와 스크린샷은 공개 스킬에 넣지 않는다.

후속 답변에서 사용자가 더미데이터 사용을 허용했다. 이번 시험에 사용한 값은 2026-10-16 15:00~16:00, 사유 `스킬 검증용 더미 입력(상신하지 않음)`이다. 이는 이번 시험용 값이며 다음 실행의 기본값이 아니다. 실제 화면에서 근무시간·기존 일정과 충돌하면 테스트 범위 안에서 조정하고 기록한다. 사용자는 처음 Edge에 로그인해 두었으나 현재 도구에 Edge가 연결되지 않아 Chrome에 로그인했고, 그 세션에서 위의 실기 검증을 완료했다.
