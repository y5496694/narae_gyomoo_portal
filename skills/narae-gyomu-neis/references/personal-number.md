# 본인 NEIS 개인번호 조회와 요청된 명부 입력

2026-11-04 충북 4세대 나이스에서 본인의 개인번호 조회와 사용자가 지정한 Google Sheets 명부 한 칸 입력을 확인했다. 실제 번호·이름·로그인 ID·시트 URL은 이 문서나 테스트에 보관하지 않는다.

## 조회

1. 업무포털 공통 절차로 로그인하고 사용자와 소속을 확인한다. 등록된 보안 문서 사용이 허가된 업무는 실행기가 직접 로그인한다. 도구 호환 문제로 인증서 제출 전에 멈추면 공통 로그인 문서의 복구 절차를 먼저 적용한다.
2. 업무포털의 **업무바로가기 → 교원인사기본사항**을 현재 DOM에서 찾아 연다. 이 바로가기는 기존 나이스 탭과 별도의 나이스 탭을 만들 수 있으므로 `tabs`로 열린 실제 탭을 확인한다. 암호화된 링크 주소를 복사하거나 직접 API를 호출하지 않는다.
3. 실제 나이스 **기본사항 → 근무사항**에서 **개인번호**와 같은 화면의 성명·기관을 대조한다. 개인번호는 이 화면의 원문을 복사해 사용한다. 로그인 ID·인증서 이름·옆 사람의 명부 값으로 추정하지 않는다.
4. 바로가기가 없으면 현재 나이스 메뉴 검색이나 인사 메뉴에서 본인 기본사항을 찾는다. 권한과 화면이 다르면 실제로 확인한 경로까지만 보고한다. 인사기록 수정·출력은 조회에 필요하지 않다.

## 사용자가 지정한 명부에 입력

- 시트 URL은 사용자가 맡긴 쪽지 등 실제 자료에서 확인하고, 해당 서비스의 전용 편집 도구를 사용한다. 조회 허가만으로 다른 문서에 옮기지 않는다.
- 실제 파일·탭·개인번호 열 제목을 확인하고 본인의 성명·소속으로 한 행을 확정한다. 제목의 연도와 탭 이름의 연도가 다를 수 있으므로 현재 메타데이터의 정확한 탭 이름을 쓴다. 동명이인이나 대상이 불명확하면 임의로 고르지 않는다.
- 대상 셀의 기존 값·수식·검증 규칙을 다시 읽는다. 기존 값이 같으면 다시 쓰지 않는다. 다른 값이 있으면 원문과 대조하고 변경 근거를 확인한다.
- 문자와 숫자로 된 식별번호를 숫자로 변환하거나 공백·접두사·앞자리 0을 추가·삭제하지 않는다. 나이스 원문을 문자열로 넣고 요청된 셀만 바꾸며 이웃 수식·서식을 유지한다.
- 저장 후 동일 셀을 재조회해 원문 전체와 일치하는지 확인한다. 완료 보고에는 입력 위치와 저장 확인 여부를 알리고, 개인번호 전체를 불필요하게 반복하지 않는다.
