# 나래교무 업무포털 — 나이스

[업무포털 공통 지침](../narae-gyomu-work-portal/SKILL.md)을 읽고, 로그인/진입이 필요하면 해당 스킬의 공통 로그인 절차로 나이스에 들어간다. 로그인된 세션을 먼저 사용한다. 나이스 웹 화면은 브라우저 컨트롤로 처리한다.

연가/조퇴 요청은 [조퇴 초안·결재경로](references/leave-draft.md)를 읽는다. 실제 날짜·시간·사유·복무 종류·결재자의 현재 소속·역할·순서를 대조한다. 사용자가 더미 시험을 허용했다면 더미 값을 정하고 최종 상신 없이 확인할 수 있다. 저장된 경로를 다음 실제 신청의 정답으로 고정하지 않는다.

확인된 흐름은 **복무 → 개인근무상황관리 → 신청 → 연가/조퇴 → 승인요청 → 기안문서상신 → 개인결재선 → 지정**이다. 이 신청 화면의 승인요청은 준비창을 여는 중간 단계다. **기안문서상신 창의 최종 상신은 누르지 않는다.** 다른 화면의 같은 버튼에 이 의미를 일반화하지 않는다.

완료 보고에는 입력한 날짜·시간·사유, 경로 확인 여부, 저장 여부, **미상신** 상태와 남은 확인 사항을 넣는다. 상세 개인정보를 공개 스킬의 예제나 검증 기록에 저장하지 않는다.

다른 복무 종류·결재 상태·학적·성적 등은 현재 이 스킬에 구현하지 않았다. 추가 요청을 받으면 현재 화면에서 요청된 범위를 확인하고 지원 상태를 분명히 기록한다. 제공된 절차만으로 완료했다고 보고하지 않는다.
