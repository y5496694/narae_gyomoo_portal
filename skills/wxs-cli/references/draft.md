# 초안 설정

UTF-8 JSON을 사용한다. 상대 경로는 설정 파일 폴더 기준이며 BOM도 허용한다.

```json
{
  "expected_title": "",
  "title": "테스트",
  "body": "1. 관련: 테스트-1234(1234.1234..1)\n2. 테스트를 하고자 합니다.\n\n붙임  테스트 문서 1부.  끝.",
  "task_card": "실제 과제카드 명칭",
  "private_reasons": [6],
  "approver": {"name": "실제 결재자 이름"},
  "recipient": {"search": "부서 검색어", "name": "교육청과 부서를 포함한 실제 전체 명칭"},
  "auto_send": true,
  "attachments": ["C:\\사용자가 지정한 폴더\\첨부.pdf"],
  "save_name": "테스트"
}
```

| 항목 | 의미 |
| --- | --- |
| expected_title | 변경 전 현재 제목. 새 양식이면 빈 문자열. 필수 |
| title | 입력할 제목. 필수 |
| body / body_file | 본문 문자열 또는 UTF-8 텍스트 파일, 둘 중 하나. CRLF로 줄바꿈 변환 |
| task_card | 실제 후보의 정확한 과제카드 명칭 |
| private_reasons | 비공개 선택과 사유 1~8호. `[6]`이면 6호만 선택 |
| approver | 현재 조직의 결재자 1명. 이름 중복이면 실제 확인한 id도 지정 |
| recipient.search / name | 기관 검색어 / 검색 결과 전체 표시명과 정확히 일치하는 명칭 |
| auto_send | true만 지원. 대외 시행·발신명의 선택·기본 관인 1개 필요 |
| attachments | 실제 파일 경로 목록. 파일명·크기는 파일에서 산출 |
| save_name | 있으면 마지막에 서버 임시저장, 없으면 열린 양식에 입력만 함 |

선택 항목 생략은 해당 항목 유지다. `attachments: []`는 기존 파일을 지우지 않는다. 공개/부분공개 전환·자동발송 해제·기존 경로/수신자/첨부 교체는 지원하지 않는다. 비공개 사유는 사용자가 지정한 값을 따른다.

현재 지원은 **기안자만 있는 경로에 결재자 1명**, **빈 수신자 목록에 기관 1곳**, **빈 첨부 목록에 지정 파일 추가**다. 기존 데이터를 삭제하며 맞추지 않는다. 과제카드도 실제 이름과 대조한다. 과거 “특수교육교과활동” 요청의 실제 후보는 “특수교과교육활동”이었지만 이를 자동 치환하는 규칙으로 만들지 않는다. 개인 ID·기관 ID는 하드코딩하지 않는다.

자동발송은 앱의 설정 확인 함수를 호출하며 실제 발송을 요청하지 않는다. 이 문서를 사용자가 나중에 결재올림하고 최종 결재가 완료되면 앱 정책에 따라 발송될 수 있다.

같은 임시저장 이름은 기본적으로 취소한다. 해당 초안을 교체하라는 사용자 지시가 있을 때만 `--replace-existing`을 붙인다. 네이티브 메시지는 정확한 이름의 교체 확인과 저장 성공 메시지만 처리한다. 다른 메시지는 열린 채로 둔다.

```powershell
python $wxsCli draft --config .\draft.json
python $wxsCli draft --config .\draft.json --hwnd 123456 --apply
python $wxsCli save-draft --name '테스트' --expected-title '테스트' --hwnd 123456 --apply
```

작업은 원자적 트랜잭션이 아니며 자동 롤백도 없다. 실패하면 입력 내용과 선택창이 남을 수 있다. `draft-status` 및 `completed_steps`를 보고 완료 항목을 뺀 설정으로 이어가며 `expected_title`도 현재 값으로 고친다. 저장 결과 불명은 임시보관함에서 확인한다.

첨부 계획에는 로컬 파일의 크기와 SHA-256이 포함된다. 입력 전과 각 첨부 직전에 원본을 다시 읽어 같은 크기로 바뀐 파일도 중단한다. 이는 로컬 원본의 변경 검사이며, 서버에 저장된 첨부 바이트를 검증했다는 뜻은 아니다. 임시저장 후에는 같은 초안을 재열람해 본문·필드·첨부를 대조한다.
